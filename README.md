# DevOps Engineer Portfolio — GitHub Pages

Personal portfolio for **Durga Prasad Thota**, focused on DevOps, cloud infrastructure, CI/CD, Infrastructure as Code, Kubernetes, automation, and observability.

## Quick start

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Copy all files in this folder into the repository root.
3. Replace the placeholder GitHub and LinkedIn links in `index.html`.
4. Commit and push.
5. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, then choose `main` and `/ (root)`.
6. Your site will be available at `https://YOUR-USERNAME.github.io/`.

## Customize

- `index.html` — content, projects, links, experience.
- `assets/css/style.css` — visual design and responsive layout.
- `assets/js/main.js` — mobile navigation behavior.
